## 键盘布局

使用五行键盘，顶部为独立数字行。字母键和数字键的滑动输入、长按默认选项均对应键面上的副符号；长按菜单保留重音字母和分数等选项。

A/L 两侧留白不显示额外按键。需要点击两侧留白输入 A/L 时，可在虚拟键盘设置中开启“将按键范围扩展至边缘”。文字键盘使用加宽退格键，数字键盘保持各列对齐。
